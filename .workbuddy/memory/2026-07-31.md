## 修复管理员更新收款码后用户端不同步
- **根因**: showPayModal/showUserRecharge 直接读取内存中的 PERM.payQRCode，没有先 loadPerm() 从 localStorage 重新加载最新数据；跨标签页/设备更无法感知变化
- **修复**:
  1. 新增公共函数 renderPayQRCode(containerId) 统一渲染二维码
  2. showPayModal/showUserRecharge 开头调用 loadPerm() 重新读取最新 localStorage
  3. adminUploadQR 上传后使用 renderPayQRCode 同步刷新所有可能打开的弹窗
  4. adminClearQR 删除后恢复为默认二维码（loadPerm 填充默认值），同步刷新弹窗
  5. 新增 refreshUserQR() 手动刷新按钮——充值弹窗中添加"🔄 刷新二维码"按钮
  6. 添加 window.addEventListener('storage', ...) 跨标签页自动同步——其他标签页修改 PERM 后自动重新加载并刷新弹窗
- **跨设备限制**: localStorage 是本地存储，不同设备间无法自动同步。管理员在A设备上传的新二维码，B设备的用户无法自动看到。需要用户刷新页面或点击"🔄 刷新二维码"按钮（但这也只对同设备localStorage有效）。跨设备同步需引入云端存储
